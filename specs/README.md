# Document feature specifications

Use the local [workflow](../.specify/README.md) and [templates](../.specify/templates/)
for accepted behavior changes. Each feature owns spec.md, plan.md, tasks.md and
handoff.md. Select the next unused three-digit ID when starting work; the highest
number does not imply active work.

No implementation feature has been selected in this migration. No assessment or
coding-lab feature history was copied. The [readiness review](../docs/document-readiness.md)
records current behavior, evidence gaps and proposed next work; it is not a claim
that those fixes are implemented or approved.
